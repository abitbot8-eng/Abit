Nova - Android Studio project (Jetpack Compose)

Open: Android Studio (Hedgehog or newer) > File > Open > select this "Nova" folder > wait for Gradle sync > Run.
Build APK: Build > Build Bundle(s) / APK(s) > Build APK(s)
Output: app/build/outputs/apk/debug/app-debug.apk

Only permission used: POST_NOTIFICATIONS (asked when you send a test notification).
